# Portfolio quality notes

## Business problem

The site helps a language school explain its courses and convert interested visitors into pre-enrollment contacts without requiring a login or payment flow.

## Demonstrative targets

These are project targets, not measured business results:

| Signal | Target |
| --- | --- |
| Main CTA completion | 8–15% of qualified visits |
| Mobile performance | Lighthouse Performance 90+ |
| Accessibility | Lighthouse Accessibility 95+ |
| Lead response | First response within one business day |

## Accessibility checklist

- [x] Semantic page sections and visible headings
- [x] Responsive layout
- [ ] Verify keyboard focus on every interactive element before release
- [ ] Verify contrast after any visual brand update
- [ ] Run Lighthouse on the deployed URL

No learner, enquiry or enrollment data is committed to this repository.
